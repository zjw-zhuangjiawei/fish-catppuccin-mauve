# Catppuccin Mauve for Fish

A purple-shifted variant of [Catppuccin](https://github.com/catppuccin/fish) for [Fish shell](https://fishshell.com/).

## What's different

This theme shifts key colors toward **mauve/purple** for a more unified purple aesthetic:

| Element | Original Catppuccin | Mauve Variant |
|---------|---------------------|---------------|
| Command | Blue | **Mauve** |
| Keyword | Mauve | Mauve (unchanged) |
| End | Peach/Orange | **Mauve** |
| Operator | Pink | **Mauve** |
| CWD | Yellow | **Mauve** |
| User | Teal | **Mauve** |
| Host | Blue | **Mauve** |
| Pager prefix | Pink | **Mauve** |

## Installation

### Fisher

```fish
fisher install zjw-zhuangjiawei/fish-catppuccin-mauve
```

### Manual

1. Copy the theme file to your Fish themes directory:

```fish
cp themes/catppuccin-mauve-mocha.theme ~/.config/fish/themes/
```

2. Apply the theme:

```fish
fish_config theme choose catppuccin-mauve-mocha
```

## Available Themes

- `catppuccin-mauve-latte` (Light)
- `catppuccin-mauve-frappe` (Dark)
- `catppuccin-mauve-macchiato` (Dark)
- `catppuccin-mauve-mocha` (Dark)
